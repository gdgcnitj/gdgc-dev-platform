## Text sizes

| Reference role | Size | Line height | Letter spacing |
| --- | --- | --- | --- |
| Display text | `128px` | `100%` | `-6%` |
| Heading | `96px` | `110%` | `-6%` |
| Sub-heading | `64px` | `120%` | `-6%` |
| Para 1 | `48px` | `120%` | `-6%` |
| Normal texts | `36px` | `120%` | `-6%` |
| Small texts | `24px` | `120%` | `-6%` |

These names and sizes reproduce the supplied text scale.
In CSS, `-6%` tracking corresponds to `letter-spacing: -0.06em`.
The line-height ratios are `1`, `1.1`, and `1.2`.

## Proposed web use

These points are project recommendations for review.

- Use white and black for the main reading surfaces.
- Use the four brand colors as accents.
- Use one primary font for navigation, body text, and controls.
- Use the other fonts for selected display elements.
- Adapt display sizes to the screen width.
- Choose body sizes that remain readable on mobile screens.
- Check text contrast for each foreground and background pair.
- Define font weights, spacing, and component states during design.
