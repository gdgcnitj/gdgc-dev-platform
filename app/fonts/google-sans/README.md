# Google Sans

`GoogleSans-Latin.woff2` is the Latin web font served by Google Fonts, version path `v71`.
The file supports the regular and medium weights used on the home page.
Next.js serves the file locally through `next/font/local`.

Source: [Google Fonts](https://fonts.google.com/specimen/Google+Sans).
Font project: [Google Sans](https://github.com/googlefonts/googlesans).
The font license is in [OFL.txt](OFL.txt).
